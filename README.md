# लक्ष्य ट्रैकर · Target Tracker

Team ke daily / weekly / monthly targets track karne wala app (GitHub Pages + Firebase).

## Files
```
index.html
css/style.css
js/config.js   <- yahan apna Firebase link daalna hai
js/app.js
```

## Setup
1. Firebase Realtime Database banayein (test mode) aur uska link copy karein.
2. `js/config.js` mein `FIREBASE_DB_URL` ke andar wo link paste karein.
3. Saari files GitHub repo mein upload karein.
4. Settings -> Pages -> Branch: main, folder: / (root) -> Save.
5. Mila hua link team ko bhej dein. Pehla sign up karne wala Admin banta hai.
